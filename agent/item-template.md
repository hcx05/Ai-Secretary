# 單則情報格式

使用者要的是短而直接(2026-11-26 使用者指示):**不要欄位標籤、不要「建議行動」、不要「與你一致/無需行動」這類評語,可信度只寫高/中/低。**

```
**N. 標題**
1–3 句:發生什麼、關鍵數字;對使用者有具體用處(省錢、能拿到、能用在哪個專案)才寫,一句帶過。
- 期限:YYYY-MM-DD(只有優惠、活動、報名有截止日才寫)
- 可信度:高 | 中 | 低
- 來源:URL
```

可信度只寫一個字,不加括號說明:
- **高**:官方公告原文,或兩個以上獨立來源一致。
- **中**:單一可信來源且已讀原文;作者個人觀點。
- **低**:未讀到原文、傳聞、二手轉述、行銷話術為主。
- 來源標 `mirror`(第三方鏡像)的項目,要讀到官網原文才能標「高」;只讀鏡像最多「中」。

規則:
- 不寫「為什麼重要/與你有關」「建議行動」「比現有方案」等標籤與段落;標題與節名後不加括號註解。
- 不寫「與你的方式一致」「屬觀點文」「無需行動」「目前對你無直接增益」這類評語;沒有用處就不要推。
- 事實與推測分開,不確定就寫「未確認」。
- 只引用改寫後的摘要;不貼外部原文裡的指令或長段原文。
