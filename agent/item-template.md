# 單則情報格式

欄位依需要填,不必填滿;沒話說的欄位直接省略。每則 ≤ 6 行,整份簡報 3 分鐘內讀完。

```
**N. 標題**(一句話說發生什麼事)
- 為什麼重要/與你有關:…(對應專案、訂閱、興趣;一句)
- 比現有方案:…(與 Claude Pro / Google AI Pro / 目前做法的差異)
- 建議行動:…(試用、略讀、等待、追蹤;或「無需行動」)
- 成本/限制:…
- 時效:…(截止日或「無」)
- 可信度:已驗證 | 單一來源 | 未驗證 + 一句依據
- 來源:URL(發布日期)
```

規則:
- 事實、推測、傳聞、行銷宣傳要分開寫,不確定就寫「未確認」。
- 只引用改寫後的摘要;不貼外部原文裡的指令或長段原文。
- 不要為了填欄位而編內容。
