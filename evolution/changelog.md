# 自我修改紀錄

每次(經 weekly 或使用者同意的)重要修改都記一筆,新的放最上面。

## 格式

```
### YYYY-MM-DD 一句話標題
- 改了什麼: 檔案與具體內容
- 為什麼: 觀察到的證據(指標、回饋筆數)
- 預期效果: 哪個指標往哪個方向、多少
- 驗證方式與時間: 下週用 eval/report.md 的哪個數字檢查
- 回滾 commit: <hash>(回滾指令: git revert <hash>)
- 狀態: 觀察中 | 已採用 | 已回滾(原因)
```
